# UI assets

[Manrope variable font](https://github.com/google/fonts/blob/main/ofl/manrope/Manrope%5Bwght%5D.ttf) is self-hosted as `manrope-variable.ttf`. Downloaded from the Google Fonts repository on September 21, 2026. The adjacent `OFL.txt` contains its SIL Open Font License.

The desktop/web stylesheet loads this font locally. It makes no Google Fonts runtime request. Pip dice use CSS geometry and interface icons use authored inline SVG; no generated or stock raster art ships in this design.
