# Proposed 1.0 testing notes

Draft only. No signed candidate has been accepted or uploaded.

Before inviting testers, bind these notes to the exact source commit, version, build and TestFlight build ID in candidate.json. Confirm the shipped app's behavior before replacing this draft with tester-facing copy.

Test offline cold launch, all approved dice modes, solo and three AI opponents, hold/reroll/score, bonus thresholds, results, duplicate-save prevention, backgrounding, force termination and explicit resume/discard. Exercise corrupt and interrupted storage recovery, an upgrade from the previous beta, support previews and reset confirmation.

Record iPhone and iPad models/OS versions without device identifiers or tester email addresses. Include VoiceOver, large text, Reduce Motion, safe areas, allowed rotation and iPad resizing. Link sanitized results in the release tracker. A JavaScript export or mobile web adapter is not native device evidence.

External invitations require owner approval. Uploading a build does not submit it for App Review or publish it.
